Six-part dossier template

1. Edit the dossier details at the top of main.tex.
2. Replace the sample text in parts/part1.tex through parts/part6.tex.
3. Compile main.tex with pdfLaTeX. Compile twice so the table of contents is updated.
4. If using BibTeX, uncomment the bibliography lines near the end of main.tex and add a references.bib file.

The package uses standard TeX Live packages and the report class. Add image files in a figures/ directory and refer to them from a part file.
